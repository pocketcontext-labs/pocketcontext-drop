# Drop 0.5.1

Crew deployments now offer all eight Beta sizes. Drop suggests 4× for Crew for Drop 0.45.4-drop.4 based on its manifest. The owner can select 1× for 256 MiB of memory, one quarter of a CPU and 2 GiB of persistent storage. The server still enforces account and host capacity limits.

The apps list and deployment screen show the assigned HTTPS address as soon as it is available. Owners can open or copy it while the app starts. The Live indicator still requires a successful HTTPS readiness check.

The upgrade preserves existing app sizes, volumes and placement settings. See [Upgrades](../upgrades.md#from-050-to-051).
