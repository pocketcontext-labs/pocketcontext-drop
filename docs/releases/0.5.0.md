# Drop 0.5.0

Drop Beta gives an invited account a guided deployment flow for approved PocketContext binaries. Choose a file, sign in by email, select a size and deploy it. The reader shows progress and exposes the app's HTTPS link once its current deployment answers a public sign-in readiness check.

Crew for Drop 0.45.4-drop.4 is the first release with a manifest. During release admission, an operator verifies its SHA-256 and inspects the executable in a disposable NibRunner microVM. Drop caches the result for that exact digest and inspection contract. Uploading a modified executable fails before activation. Revoking a release stops its managed Beta apps.

One size unit allocates 256 MiB of memory, one quarter of a CPU and 2 GiB of persistent storage. Crew's resource minimum permits sizes 4× through 8×. Fractional CPU quotas require support from both the node agent and NibRunner. Failed uploads and placements can be retried on the prepared app.

New Beta accounts require an invitation, verified email credentials and acceptance of the published terms. The host list and reviewed legal documents are operator configuration. Customer availability depends on an eligible host and completed legal publication.
