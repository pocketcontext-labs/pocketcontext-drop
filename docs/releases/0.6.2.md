# Drop 0.6.2

Visitors can join the waitlist from the email sign-in screen or while entering a sign-in code. They review the waitlist terms, request a six-digit verification code and enter it to join. If verification fails, they can retry. Signing in to Drop still requires an invitation or an existing account.

To upgrade from 0.6.1, back up the project and current Drop executable, install the verified release and restart the control plane.
