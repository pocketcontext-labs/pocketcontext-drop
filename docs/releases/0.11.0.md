# Drop 0.11.0

Every node is now equal. Each node can run its own Cloudflare Tunnel in front of its private gateway, and its agent reports the tunnel ID (`DROP_AGENT_TUNNEL_ID`). With `DROP_DNS_ZONE_ID` and `DROP_DNS_TOKEN_FILE`, the control plane keeps one proxied DNS record per placed app pointing at the tunnel of the app's node, so any node can serve any app and a move updates the record within 30 seconds. Drop touches only the records it created (comment `drop-managed`) and never takes over a name that already has another record, so a zone wildcard can keep serving apps on nodes without a tunnel during a migration. See [Per-app DNS records](../hosting.md#per-app-dns-records).

Drop Beta's placement pool is a field on the node record. Admins set it with `node.set_pool` (`drop node set-pool NODE beta|owner|none`, or Pool on the reader's Nodes page). The `DROP_BETA_NODES` and `DROP_BETA_OWNER_NODES` lists still work and are deprecated.

Back up the hosted project before upgrading. One schema migration runs on the first start. See the [upgrade instructions](../upgrades.md#from-0100-to-0110).
