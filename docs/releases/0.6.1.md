# Drop 0.6.1

The Nodes admin panel is centered. Its Host ID hint is readable, and the State selector and Rotate action align across rows. On the Users page, account details, Role, Quota and Suspend line up with their columns. Both pages accommodate long identifiers and keep controls accessible on mobile.

The deployment screen calls the upload a PocketContext app or an app file. File validation still checks that the upload is a supported Linux executable.

To upgrade from 0.6.0, back up the project and the existing Drop executable, install the verified release and restart the control plane. This reader update uses the 0.6.0 database schema.
