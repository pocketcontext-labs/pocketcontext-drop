# Drop 0.6.0

Visitors can request a Beta invitation, accept the waitlist terms and verify their email with a six-digit code. Verified entries appear in the administrator’s Waitlist page. Inviting a person queues a welcome message with an activation link. The recipient signs in with a fresh email code and accepts the Beta service terms.

Administrators can search the list, resend or revoke a pending invitation, suspend an active account, or restore access. Suspension ends access to the control plane. Deployed apps keep serving. Users continue to deploy through the Beta flow. Hosted admins, including the platform owner, manage access and infrastructure and can no longer deploy their own apps.

This upgrade preserves existing app ownership, resources, volumes and host placement. See the [upgrade instructions](../upgrades.md#from-051-to-060).
