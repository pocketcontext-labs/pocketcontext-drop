# Drop 0.9.0

Approved owners can create Crew and Atlas workspaces with assigned addresses and persistent volumes. Both products support resource multipliers from 1× to 8× with compatible binaries. Owners select upgrades per workspace and confirm deletion with a slider. The Users directory combines accounts, invitations and verified waiting requests with filters and pagination.

Administrators stage checked official executables in Releases. Each publication requires rehearsal evidence linked to the candidate and its baseline. A publication changes the default for new workspaces. Existing workspaces keep their selected release. On activation, the catalog closes generic customer deployment entry points. Existing apps keep their data and placement.

A successful simulated €5 purchase adds 500 credits and resets the shared zero-balance allowance to 60 awake minutes. At exhaustion, Drop stops workspaces and retains volumes. The node S3 proxy reserves funds before forwarding requests and reconciles usage with provider records. Crew and Atlas manage their own verified copies and restores.
