# Origin

Internal maintenance note on where Drop comes from. It is the one file that may name the template identity (`tests/identity_check.py` allows it).

Drop (PocketContext Drop) was derived on 2026-11-19 from `pocketcontext-labs/pocketcontext-template` release 0.4.1, commit `306f45765dc4f3c6036914135a61b8ccac402c87` of 2026-11-19T20:01:23+01:00 (TemplateContext 0.4.1: Core 0.2.0 Policy fields from template commit `4e0f1ca` and the `pocketcontext-core` v0.2.2 pin), following that release's `new-product.md` prompt: the release's source archive was downloaded, checked against its `checksums.txt` and unpacked, and the repository history starts fresh from the derived tree. The template itself derives from PocketContext (github.com/pocketcontext-labs/pocketcontext) at commit `b938b5ebcfa80173b4665491ce232c93a4bd1a68`, later updated as the template's own `docs/origin.md` at that release describes, and from the vendored PocketContext server at github.com/pocketcontext/pocketcontext commit `20843b7c888daaba55f0646dd77455b7b309d4cc` (`internal/pocketcontext/VENDORED.md`).

- **Kept:** the one-binary architecture on `pocketcontext-core` v0.2.2 (pinned in `go.mod`, not bumped), the vendored server `internal/pocketcontext/` (import paths changed only), sync-safe database handling, the single-user account with `1810000000_users.js`, `1810000200_public_password.js` and the `account_access` hooks, local authentication, remote mode, the tailcat tunnel, opt-in public HTTPS and remote MCP with the five generic tools, the public collection allowlist and the frozen anonymous route table, the SQL reader policy and `build-tags.txt`, the skill mechanism, the development launcher, the release script and the checks (`identity_check.py`, `name_check.py`, `public_routes.py`, `e2e.py`, browser checks).
- **Renamed:** TemplateContext to Drop and `templatecontext` to `drop` (command, skill, marker files, database `drop.db`, configuration `drop.json`, environment prefix `DROP`, header `X-Drop-Local-Key`, reader storage key `drop.reader.auth`, hook global `$drop`, socket host `drop.internal`), the profile registry and cache folder to `pocketcontext-drop`, the module to `github.com/pocketcontext-labs/pocketcontext-drop`, the default port from 8098 to 8100, the local account address to `account@drop.invalid` and the OAuth scope to `drop`; `Policy.Legacy` is empty. The reader mark is a drop instead of the template's speech bubble.
- **Replaced:** the template's hello-world collection `greetings` (migration, CLI, reader, skill, tests, search index and public allowlist) by the placeholder `apps` (`name`, unique `slug`) in `pb_migrations/1810000100_apps.js`, `internal/client/apps.go`, `ui/src/Apps.tsx`. It is unreleased scaffolding: Drop's real model replaces it in later milestones.
- **Removed for Linux only:** macOS and Windows (`windows-session.yml`, `install.ps1.in`, the macOS branch of `install.sh.in`, the darwin and windows release platforms and their tests, `make windows`, `scripts/zig-cc`, the MinGW license notices, the Windows test matrix and Windows-specific test branches). `cmd/drop/main_other.go` refuses every system but Linux. The vendored server keeps its upstream `tracing/platform_windows.go`, because `internal/pocketcontext/` changes only in import paths.
- **Removed as template-only:** `template.json`, `prompts/new-product.md`, the template's release notes (`docs/releases/`), the template release mode of `scripts/release.py` and `.github/workflows/release.yml` (prompt and source archive), and the template section of `AGENTS.md`.

- **Changed for hosted multi-user (milestone M2, on `pocketcontext-core` v0.3.0):** Drop serves people only in hosted mode with several accounts (`Policy.Accounts` = `AccountsMulti`), email sign-in and remote MCP, behind a TLS-terminating proxy (`--hosted-http-address`, `--hosted-proxy-header`, `--hosted-proxy-networks`). Policy, identity and copy moved from `internal/appconfig` to `internal/droppolicy` (with its own hosted route allowlist and golden table, and Crew's sign-in code email), hooks to `internal/dropserver`. Removed: native public HTTPS mode (`serve --domain` without `--hosted`, `open --public`, `internal/appconfig/public.go`, the public collection allowlist in `server.json` and `docs/https.md`), the `publicPasswordStrong` migration `1810000200_public_password.js` (never released), the tailcat `tunnel` command and the development launcher's `--tunnel`, and the five generic MCP tools (`read`, `search`, `schema`, `query`, `write`). `account_access.js` accepts several accounts; `apps` gained an owner. The Login and Connect pages of the reader come from PocketContext Crew.

Drop is a full fork. Security fixes in pocketcontext-template, PocketContext (see the template's `docs/origin.md`), the vendored server (`internal/pocketcontext/VENDORED.md`) and pocketcontext-core must be reviewed and ported by hand; a core fix ships as a tagged core release and a pin bump here.
